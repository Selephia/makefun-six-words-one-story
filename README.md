## What it is

One complete story in exactly six words, for make.fun's "Six Words, One Story" bounty. A son comes home after a long absence; the woman who answers the door does not know him. The turn lands on the last word.

## Run it

```sh
OUTPUT_DIR=./output python3 main.py
```
